# BGG Umbrella Buyer Guide

Static Thai buyer guide for comparing BGG umbrella models, designed for GitHub Pages.

## Local Use

Open `index.html` directly in a browser.

## GitHub Pages

This project is ready to serve from the repository root on the `main` branch.

## Notes

Product prices, availability, and marketplace listings can change. The page records its research date in the UI and links to source pages at the bottom.
